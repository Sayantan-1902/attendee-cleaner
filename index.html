Pipeline: isolate attendee section → drop Is-Guest & Country → merge each person's overlapping join/leave windows into true total time → strip non-digits from phone → remove duplicate emails → remove duplicate phones → keep Attended = Yes → drop blank email/phone → sort.
Total time: computed from Join/Leave timestamps with overlap merging, not by summing the minutes column — joining from two devices at once no longer double-counts. Join Time and Leave Time in the output show each person's earliest join and latest leave.
Note: phone numbers are normalized before the duplicate check, and blank phones are never treated as duplicates of each other — so no real attendee gets dropped by accident.
